# Light of Hope Organisation Website

A responsive multi-page static website starter using HTML, CSS and JavaScript.

## Pages
- index.html — Home
- about.html — About the organisation
- programs.html — Programmes
- get-involved.html — Ways to participate
- volunteer.html — Volunteer registration
- donate.html — Donation pledge information
- contact.html — Contact form
- gallery.html — Photo gallery with lightbox
- news.html — News and announcements
- admin.html — Demo administration dashboard

## Run locally
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Install/use the Live Server extension, or open `index.html` in a browser.
4. Keep the `css`, `js`, and `images` folders in the same location as the HTML files.

## Before publishing
- Replace sample text with approved organisation information.
- Add verified email, phone, physical address and registration details.
- Replace sample news with real, approved announcements.
- Use photographs you own or have permission to publish. Obtain informed consent, especially for children.
- The forms are front-end demonstrations only. They do not send or store submissions.
- The donation page does not process payments. Integrate a reputable payment provider through a secure backend; never place secret keys in browser JavaScript.
- `admin.html` is a visual demo, not a secure admin system. Do not use it to access or manage personal information.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders, keeping the folder structure.
3. In repository Settings, open Pages.
4. Choose Deploy from a branch, select `main` and `/(root)`, then save.
5. Wait for the published URL shown by GitHub Pages.

GitHub Pages hosts static files only. For secure forms, a real admin dashboard, user accounts and payment processing, connect a backend or trusted service.
